# 뷰티 스타일 AI 설명기

헤어스타일 · 네일아트 · 메이크업 · 타투 사진을 올리면 **브라우저 안에서** AI가 스타일을 한국어로 설명합니다.
서버가 없고 사진이 외부로 전송되지 않습니다. 모델은 Transformers.js 로 브라우저에서 직접 실행됩니다.

## 무엇이 나오나

| 출력 | 예시 (네일 사진) |
|---|---|
| 장르 카드 | **프렌치 네일** · 밀키화이트 · 스퀘어 · 미디엄 |
| 트렌드 키워드 | `오피스네일` `쇠맛 네일` `자석네일` 처럼 인스타그램 · 네이버에서 실제로 검색하는 말 |
| 설명 문장 | "적당한 미디엄 길이에 스퀘어 쉐입, 밀키화이트 컬러를 올린 프렌치 네일입니다. 마감은 보송한 매트 마감이에요." |
| 함께 보이는 스타일 | 예) 메이크업하는 모습의 헤어 사진이면 메이크업도 함께 설명 (다른 카테고리도 25% 이상 뚜렷할 때) |
| 속성별 근거 | 그룹마다 상위 후보와 보정된 확률 막대 |
| 틀린 결과 고치기 | 항목마다 ✎ 로 정답을 고르면, 사진 없이 특징값만 저장해 다음 학습에 쓸 수 있음 |
| 해시태그 · JSON | `#프렌치네일 #오피스네일 …`, 앱 연동용 JSON |

- **분류명은 한국식**입니다. 헤어는 허쉬컷 · 태슬컷 · 히메컷 · 빌드펌 · 애쉬브라운, 네일은 자석 · 글레이즈드 · 시럽 · 치크, 메이크업은 물광 · 음영 · 과즙 · 말린장미 같은 이름을 씁니다.
- **트렌드 키워드는 속성 조합으로 만듭니다.** 예) 브라운 염색 + 쿨톤 → "차가운 애쉬브라운", 크롬 · 실버 · 메탈릭 → "쇠맛 네일", 태슬컷 + 생머리 → "칼단발".
- **타투는 트렌드 없이 장르 중심**입니다. 레터링 · 파인라인 · 블랙앤그레이 · 이레즈미 등 15개 장르와 장르 설명, 부위 · 크기 · 도안을 알려 줍니다.
- 뷰티 사진이 아니면 "뷰티 사진이 아닐 수 있어요", 사진이 너무 작으면 "세부 판단이 부정확할 수 있어요" 안내를 띄웁니다.

## 동작 구조

```
사진 ─▶ 비전 인코더로 임베딩 1회 ─┬▶ 뷰티 사진 판별 (학습 헤드)
                                  ├▶ 카테고리 판별 (학습 헤드 + 제로샷) ─▶ 1위 + 함께 보이는 2위
                                  └▶ 속성 그룹 27개 분류 (학습 헤드 + 제로샷 혼합 → 확률 보정)
                                          ▼
                    장르 · 트렌드 키워드 · 한국어 문장 · 해시태그 · JSON
      └▶ [고급 모드] 소형 VLM 이 사진을 보고 영어로 서술 → 뷰티 용어집 + 한국어 번역
```

| 모드 | 모델 | 다운로드 | 라이선스 |
|---|---|---|---|
| 기본 (기본값) | `Marqo/marqo-fashionSigLIP` | 약 94MB (q8) | Apache-2.0 |
| 정밀 | `Xenova/siglip-large-patch16-384` | 약 208MB (WebGPU q4) · 329MB (CPU q8) | Apache-2.0 |
| 고급 모드 | `onnx-community/LFM2.5-VL-450M-ONNX` | 약 420~630MB | LFM Open License v1.0 |

- **라벨 임베딩 사전 계산**: 속성 라벨 215개의 문장 임베딩을 미리 계산해 `embeddings/` 에 넣었습니다. 브라우저는 비전 모델만 받습니다.
- **학습 헤드**: 라벨 문장 임베딩에서 출발해 검수한 사진으로 보정한 경량 분류기입니다 (`heads/`, 모델마다 약 1MB). 그룹마다 제로샷과 섞는 비율을 교차 검증으로 정하고, 교차 검증 정확도가 40% 미만인 헤드는 쓰지 않습니다.
- **고급 모드**: 이 소형 VLM은 한국어로 직접 쓰면 옷 · 배경 이야기로 새는 경향이 있습니다. 그래서 영어로 먼저 관찰하게 한 뒤 문장 단위로 번역하고, 영어 원문도 함께 보여 줍니다.

## 신뢰도: 단정하는 말은 90% 이상 맞게

화면의 확률은 **보정된 확률**입니다. 학습 때 폴드 밖 예측으로 그룹마다 온도를 맞춰, "80%"라고 표시하면 실제로도 그 정도로 맞게 했습니다. 문장의 말투는 이 확률로 정합니다.

| 보정 확률 | 문장 | 실제 적중률 (기본 · 정밀) |
|---|---|---|
| 0.75 이상 | "~입니다" | **90.7% · 93.5%** (전체 판단의 53% · 62%) |
| 0.5 ~ 0.75 | "~로 보입니다" (2위가 가까우면 함께 언급) | 68.6% · 69.3% |
| 0.5 미만 | "~로 추정됩니다" + 다른 후보 제시 | 52.1% · 50.1% |

트렌드 키워드 칩과 해시태그도 보정 확률 0.5 이상일 때만 붙입니다. 적중률은 정답 후보 기준입니다 (예: 정답이 "오벌 또는 아몬드"일 때 둘 중 하나면 맞음).

검수 라벨은 Claude 가 직접 단 1·2·4차 라벨입니다. 3차(보조 에이전트) 라벨은 학습에만 쓰고 시험에는 쓰지 않았습니다.

평가 세트는 작아서 사진 한두 장에 수치가 1%p 씩 움직입니다. 그래서 판단은 표본이 7배 큰 교차 검증을 기준으로 했습니다.

### 배운 점

- **라벨의 정확도가 양보다 중요했습니다.** 검색어로 자동으로 붙인 라벨 1만 장은 효과가 없었습니다 (73.9% → 73.4%). 사진을 직접 보고 단 라벨은 280장만으로 +5.9%p 를 올렸습니다.
- **라벨 기준이 다르면 오히려 떨어집니다.** 3차 라벨(보조 에이전트)은 헤어 앞머리 · 네일 디자인 · 타투 장르에서는 도움이 됐지만, 네일 쉐입 · 립 컬러 · 염색 기법에서는 기준이 달라 정확도를 떨어뜨렸습니다. 그래서 그룹마다 검수 라벨로 효과를 재서, 도움이 되는 그룹에만 썼습니다.
- **모델마다 맞는 데이터가 다릅니다.** 4차 메이크업 라벨은 기본 모델의 메이크업을 올렸지만 (평가 71.4% → 76.2%) 정밀 모델은 떨어뜨려 (76.2% → 69.0%), 정밀 모델에는 쓰지 않았습니다.
- **두 모델 앙상블은 이득이 없었습니다.**

- **출처**: Wikimedia Commons 와 Openverse(Flickr 등)에서 상업적 이용이 허용된 자유 라이선스 사진만 모았습니다. 핀터레스트 같은 SNS 는 이용약관이 자동 수집을 금지하고 사진마다 저작권자가 따로 있어 쓰지 않았습니다.
- **배포되는 헤드의 학습 사진**: CC0 · 퍼블릭 도메인 · CC BY · CC BY-SA 만 씁니다. 개작 금지(ND) · 비영리(NC) 사진은 `train-heads.py --commercial` 로 뺍니다.
- **평가 세트**: 비영리 라이선스 사진이 섞여 있어 측정에만 쓰고 학습에는 쓰지 않습니다.
- **출처 기록**: `data/labels_clean.jsonl` 에 1,977장의 정답 · 차수 · 라벨 주체 · 원본 페이지 · 작성자 · 라이선스를 모두 남겼습니다. 사진 파일 자체는 저장소에 넣지 않습니다.
- **라벨 규칙**: 정답 후보가 여러 개면 모두 적습니다 (예: 아몬드 또는 오벌). 헤어 사진에 염색 기법 · 묶음 표시가 없으면 전체 염색 · 풀어내린 머리로 봅니다.

## 피드백으로 계속 좋아지기

상업 서비스에서 정확도를 올리는 가장 빠른 길은 실제 사용자 사진에서 틀린 사례를 모으는 것입니다. 이 앱은 사진을 저장하지 않고도 그렇게 할 수 있습니다.

1. 사용자가 결과 화면에서 ✎ 로 틀린 항목의 정답을 고르거나, 카테고리를 고칩니다 ("뷰티 사진 아님" 포함).
2. 브라우저에는 **사진 대신 모델이 뽑은 특징값(임베딩)** 과 고친 라벨만 저장됩니다. 특징값에서 원래 사진을 복원할 수는 없습니다.
3. "피드백 내보내기"로 받은 파일을 학습에 그대로 넣습니다.

```bash
python3 tools/train-heads.py --commercial ... --feedback beauty-feedback-2026-10-01.jsonl
```

사용자가 고친 사례는 모델이 틀린 사례이므로, 학습 때 잡음 필터에서 빼지 않습니다. 서비스로 운영할 때는 이 파일을 서버로 모으는 부분만 붙이면 됩니다 (사용자 동의 필요).

## 속성 사전을 고치거나 다시 학습하려면

```bash
npm i @huggingface/transformers
node tools/build-embeddings.mjs                      # taxonomy.js 수정 후 라벨 임베딩 재생성
node tools/embed-images.mjs list.json out Marqo/marqo-fashionSigLIP q8   # 사진 임베딩
python3 tools/train-heads.py --commercial --tax taxonomy.json --labels embeddings/marqo-fashionSigLIP.json \
    --train out.f32 --train-meta out.json --train-list train_list.json \
    --eval eval.f32 --eval-meta eval.json --eval-list eval_list.json --out heads/marqo-fashionSigLIP.json
```

학습이 끝나면 그룹별 정확도와 보정표(`CALIBRATION`)가 출력됩니다. 속성 사전을 바꾸면 해시가 달라져 기존 헤드는 자동으로 꺼지고 제로샷으로 동작합니다. 다시 학습하면 켜집니다.
