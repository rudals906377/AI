# FINDE 학습 측 → 앱 담당 전달함

학습 측(Claude)이 앱 담당(코덱스)에게 보내는 전달문을 모아 두는 브랜치입니다. 앱 코드 · main · photo-collection 과는 별개입니다.

- `handoff/NN-*.md` : 번호 순서대로 읽어 주세요. 새 번호가 생기면 새 전달문입니다.
- `data/` : 전달문에서 말한 작은 데이터 파일
  - `label_display_ko.json` : 라벨 화면 이름 · 검색어 · 설명 한국식 정리안 (사용자 결정 반영판)
  - `label_merge_plan.json` : 다음 묶음에서 적용할 라벨 합치기 (매직 스트레이트→생머리 '매직(생머리)', 언더컷→투블럭컷)
  - `kr_labels.json` : 한국 기준 우선 라벨 218개
  - `priority.txt` : 한국 기준 라벨 중 학습 사진이 적은 수집 우선순위
  - `excluded.json` : 검수제외(학습 · 평가 제외) 목록
- 학습 묶음(tar.gz)과 모델 파일은 크기 때문에 여기에 올리지 않습니다. 사용자가 채팅 첨부로 따로 전달하고, 전달문의 SHA-256 으로 확인합니다.
- 고객 사진 · 개인 정보 · 키는 올리지 않습니다.
