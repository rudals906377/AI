# 예시 사진 출처

예시 사진 100장(헤어 32 · 네일 27 · 메이크업 21 · 타투 20)은 저장소 소유자가 GitHub 에 올린 한국 스타일 사진(`헤어/`, `네일아트/`, `메이크업/`, `타투/`)을 모두 등록한 것입니다.

- `python3 tools/make-samples.py` 로 만듭니다. 폴더에 사진을 더 넣고 다시 실행하면 예시가 갱신됩니다.
- 분석용 사진은 긴 변 900px, 목록용 작은 사진(`thumbs/`)은 240px 로 줄였고, 촬영 위치 같은 EXIF 정보는 지웠습니다.
- 원본 사진의 권리는 확인되지 않았습니다. 상업적으로 쓰기 전에 사진마다 권리를 확인하거나, 권리가 확인된 사진으로 바꿔야 합니다.
- 이 사진들은 학습 데이터(5차)에도 들어 있어, 예시 결과는 처음 보는 사진보다 정확하게 나올 수 있습니다.
