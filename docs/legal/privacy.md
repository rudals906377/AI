[운영자 이름](이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 빠르게 처리하기 위해 이 처리방침을 둡니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 올린 사진 | **수집하지 않습니다.** 이용자의 기기 안 브라우저에서만 분석하고, 어떤 서버로도 보내지 않습니다. |
| 분석 결과 | 수집하지 않습니다. 화면에만 보입니다. |
| 피드백(틀린 결과 고치기) | 이용자의 브라우저에만 저장됩니다. 운영자에게 자동으로 오지 않습니다. 사진은 들어가지 않습니다. |
| 회원 가입, 로그인, 결제, 광고 | 없습니다. |
| 운영자가 받는 개인정보 | 누군가 운영자에게 직접 보낼 때의 정보뿐입니다 (이메일 문의, 권리 침해 신고, 전문가 검수 결과 파일). |
| 접속 기록 | 웹사이트를 전달하는 Hugging Face(미국)와 jsDelivr가 일반 웹사이트처럼 접속 기록(IP 주소 등)을 받습니다. 운영자는 이 기록을 받지 않습니다. |
| 문의 | [연락처 이메일] |

## 제1조 (개인정보의 처리 목적)

운영자는 다음 목적으로만 개인정보를 처리합니다. 목적이 바뀌면 미리 알리고, 필요하면 동의를 받습니다.

1. **문의 응답**: 이용자가 이메일로 보낸 질문, 오류 신고, 의견에 답합니다.
2. **권리 침해 신고 처리**: 예시 사진 등에 관한 초상권·저작권 침해 신고를 확인하고 처리합니다.
3. **모델 개선**: 이용자가 "피드백 내보내기" 파일을 스스로 보내 주거나, 운영자가 부탁한 헤어·네일·메이크업·타투 전문가가 검수 결과 파일을 보내 주면, 모델 정확도를 확인하고 다시 학습하는 데 씁니다.

서비스의 핵심 기능(사진 분석)에는 개인정보를 수집하지 않습니다.

## 제2조 (처리하는 개인정보의 항목)

### 1. 운영자가 받는 정보

| 상황 | 항목 | 필수 여부 |
|---|---|---|
| 이메일 문의 | 이메일 주소, 문의 내용 | 필수 |
| 이메일 문의 | 이름, 첨부 파일 | 선택 (이용자가 보낸 경우) |
| 권리 침해 신고 | 이메일 주소, 이름, 침해를 주장하는 사진과 권리 내용 | 필수 |
| 피드백 파일 (이용자가 보낸 경우만) | 보낸 이메일 주소, 파일 속 숫자 특징값(임베딩), 고친 라벨, 모델 이름, 저장 시각. 사진은 없음 | 이용자 선택 |
| 전문가 검수 결과 파일 (검수자가 보낸 경우만) | 검수자 이름, 전문 분야, 사진 파일 이름, 검수 결과 | 필수 (검수 참여 시 따로 안내하고 동의를 받음) |

이메일에 다른 사람의 사진이나 건강 정보는 넣지 마세요. 넣었다면 운영자는 답변에 필요하지 않은 정보를 바로 지웁니다.

### 2. 운영자가 받지 않는 정보

| 정보 | 처리 방식 |
|---|---|
| 이용자가 올리거나 찍은 사진 | 이용자 기기의 브라우저 메모리에서만 분석합니다. 서버로 보내지 않고, 저장하지 않습니다. 페이지를 닫거나 다른 사진을 고르면 사라집니다. |
| 사진 속 위치정보(EXIF) 등 부가 정보 | 사진이 기기 밖으로 나가지 않으므로 운영자는 받지 않습니다. |
| 분석 결과 | 화면에만 표시합니다. 이용자가 복사하지 않는 한 어디에도 남지 않습니다. |
| 피드백 데이터 | 이용자의 브라우저 저장 공간에만 남습니다 (제11조). |
| 계정, 결제, 연락처, 위치 | 서비스에 이런 기능이 없습니다. |

### 3. 얼굴 사진에 대하여

- 얼굴 사진은 다루기에 따라 특정인을 알아보는 데 쓰일 수 있는 민감한 정보입니다.
- 「개인정보 보호법 시행령」 제18조는 "특정 개인을 알아볼 목적으로 일정한 기술적 수단을 통해 생성한 신체적 특징 정보"(생체인식 특징정보)를 민감정보로 봅니다.
- 이 서비스는 사람을 알아보거나 구별하는 기능이 없습니다. 사진에서 스타일(헤어, 네일, 메이크업, 타투)의 특징만 계산합니다.
- 색상 칩을 만들 때는 부위를 찾는 AI 모델(MediaPipe)이 머리카락 영역, 얼굴의 입술·눈두덩·볼 위치, 손끝 위치를 찾습니다. 찾은 위치는 그 부분의 색을 뽑는 데만 쓰고 바로 버립니다. 저장하거나 사람을 구별하는 데 쓰지 않습니다.
- 계산은 이용자의 기기 안에서만 이루어집니다. 운영자는 얼굴 사진도, 그 특징값이나 얼굴 위치 정보도 받거나 저장하지 않습니다.

> `검토 필요` (1) 시행령 제18조 제3호의 문구는 검색 결과로 확인했고 law.go.kr 원문은 끝까지 열람하지 못했습니다. 게시 전 원문 대조가 필요합니다. (2) 피드백 데이터의 특징값(임베딩)은 스타일 분류용이지만, 같은 사람의 다른 사진과 비교하는 데 쓰일 가능성을 완전히 배제할 수는 없습니다. 운영자가 이 값을 수집하게 되면(제14조) 개인정보 또는 민감정보에 해당하는지 판단이 필요합니다.

## 제3조 (개인정보의 처리 및 보유 기간)

| 정보 | 보유 기간 |
|---|---|
| 이메일 문의 기록 | 답변을 마친 날부터 [1년] 동안 보관한 뒤 지웁니다. 이용자가 먼저 삭제를 요청하면 바로 지웁니다. |
| 권리 침해 신고 기록 | 처리를 마친 날부터 [3년] 동안 보관한 뒤 지웁니다. 같은 사진에 대한 분쟁에 대비하기 위해서입니다. |
| 피드백 파일 | 학습 데이터에 넣을 때 보낸 사람의 이메일 주소와 분리해 보관합니다. 특징값과 라벨은 받은 날부터 [3년], 이메일은 위 문의 기록과 같은 기간 보관합니다. |
| 전문가 검수 결과 | 받은 날부터 [3년] 또는 검수자가 삭제를 요청할 때까지. 학습 기록에는 검수자 이름 대신 [검수자 번호]만 남깁니다. |

다른 법령에 따라 보존해야 하는 경우에는 그 기간 동안 보관합니다. 현재 해당 사항은 없습니다.

> `검토 필요` 보유 기간 [1년]·[3년]은 운영자가 정할 값입니다. 분쟁 대비 보관 기간이 과도하지 않은지 확인이 필요합니다.

## 제4조 (개인정보의 제3자 제공)

운영자는 개인정보를 다른 사람에게 제공하지 않습니다. 다만 법률에 특별한 규정이 있거나, 수사기관이 법령에 따른 절차로 요청하는 경우에는 예외로 합니다.

## 제5조 (개인정보 처리의 위탁)

운영자는 개인정보 처리 업무를 다른 사람에게 맡기지 않습니다.

다만 문의 이메일은 [이메일 서비스 이름, 예: Gmail]을 통해 받습니다. 이메일 서비스 회사가 이메일을 보관하는 것이 처리 위탁에 해당하는지는 아래 `검토 필요`를 보세요.

> `검토 필요` 운영자가 개인 이메일 계정(예: Google의 Gmail)으로 문의를 받으면, 이메일 서비스 회사가 이메일을 국외 서버에 보관합니다. 이것을 처리 위탁·국외 이전으로 적어야 하는지, 적는다면 제6조 표에 추가할지 확인이 필요합니다. 지금은 제6조 표에 조건부로 넣었습니다.

## 제6조 (개인정보의 국외 이전)

이 서비스는 직접 운영하는 서버가 없습니다. 웹 페이지와 AI 모델은 해외 회사의 서버에서 이용자의 브라우저로 바로 전달됩니다. 이 과정에서 각 회사는 일반 웹사이트와 같은 접속 기록을 자기 정책에 따라 처리합니다. **운영자는 이 접속 기록을 받거나 볼 수 없습니다.**

> - 국외 이전으로 본다면 근거 조항(제28조의8 제1항 각 호 중 어느 것인지)을 이 절에 적어야 합니다 (작성지침 권고).
> - Hugging Face 처리방침은 2023. 3. 28. 기준, jsDelivr 처리방침은 GitHub 공개본 2023. 11. 23. 기준으로 확인했습니다. 게시 직전에 다시 확인하세요.
> - 운영자가 Space 설정에서 방문자 통계·로그를 볼 수 있는지 Hugging Face 계정 화면에서 확인하세요. 볼 수 있다면 운영자가 접속 기록을 처리하는 것이 되어 이 방침을 고쳐야 합니다.

## 제7조 (개인정보의 파기 절차와 방법)

1. 보유 기간이 끝나거나 처리 목적을 이루면 개인정보를 지체 없이 지웁니다.
2. 이메일은 메일함과 휴지통에서 영구 삭제합니다. 첨부 파일을 내려받았다면 그 파일도 지웁니다.
3. 종이 문서는 분쇄하거나 태웁니다.
4. 이용자의 브라우저에 남은 정보(피드백, 모델 파일)는 운영자가 지울 수 없습니다. 이용자가 제11조의 방법으로 지웁니다.

## 제8조 (정보주체와 법정대리인의 권리와 행사 방법)

1. 이용자는 운영자가 가진 자신의 개인정보에 대해 언제든 다음을 요구할 수 있습니다.
   - 열람
   - 정정·삭제
   - 처리 정지
   - 동의 철회
2. [연락처 이메일]로 요청하면 됩니다. 운영자는 [10]일 안에 처리하고 결과를 알려 드립니다.
3. 법정대리인이나 위임받은 사람을 통해서도 요청할 수 있습니다. 이때는 위임 사실을 확인할 수 있는 자료가 필요합니다.
4. 사진, 분석 결과, 피드백 데이터는 운영자가 가지고 있지 않습니다. 이 정보는 이용자의 기기에서 직접 확인하고 지울 수 있습니다.
5. 이용자는 다른 사람의 사진을 올릴 때 그 사람의 권리를 침해하지 않도록 주의해야 합니다.

> `검토 필요` 「개인정보 보호법」 제37조의2(자동화된 결정에 대한 정보주체의 권리)는 완전히 자동화된 시스템으로 개인의 권리·의무에 중대한 영향을 주는 결정을 할 때 적용됩니다. 이 서비스는 스타일 설명만 하고 운영자가 개인정보를 받지 않으므로 해당하지 않는다고 봤습니다. 확인이 필요합니다.

## 제9조 (만 14세 미만 아동의 개인정보)

운영자는 서비스 이용을 위해 아동의 개인정보를 수집하지 않습니다. 만 14세 미만 아동이 문의를 보내려면 법정대리인(부모 등)의 동의가 필요합니다(「개인정보 보호법」 제22조의2). 법정대리인의 동의 없이 받은 것을 알게 되면 바로 지웁니다.

## 제10조 (개인정보의 안전성 확보 조치)

운영자는 「개인정보 보호법」 제29조에 따라 다음 조치를 합니다.

1. **수집하지 않는 설계**: 사진을 서버로 보내지 않고 기기 안에서 분석하도록 만들었습니다. 운영자에게 서버와 데이터베이스가 없습니다.
2. **암호화 전송**: 서비스는 HTTPS로만 제공됩니다.
3. **접근 제한**: 문의 이메일 계정은 운영자 본인만 쓰고, 2단계 인증을 켭니다.
4. **최소 보관**: 보유 기간이 지난 문의는 지웁니다.
5. **외부 코드 관리**: 외부 라이브러리는 버전을 고정해서 불러옵니다(Transformers.js 4.3.0, MediaPipe Tasks Vision 1.0.1, Pretendard 1.3.9).
6. **예시 사진 정리**: 예시 사진은 촬영 위치 등 부가 정보(EXIF)를 지운 뒤 게시합니다.

> `검토 필요` 개인 운영자에게 요구되는 안전조치 수준(「개인정보의 안전성 확보조치 기준」 고시)과 맞는지 확인이 필요합니다. 외부 스크립트에 무결성 검사(SRI)를 붙이는 것도 기술적으로 검토할 만합니다.

## 제11조 (자동으로 정보를 저장하는 장치의 설치·운영과 거부)

운영자는 쿠키를 쓰지 않습니다. 이용 기록 분석 도구나 광고 추적 도구도 쓰지 않습니다. 다만 서비스가 동작하려면 이용자의 브라우저에 다음 정보가 저장됩니다. 이 정보는 운영자에게 보내지지 않습니다.

| 저장 위치 | 저장되는 것 | 언제 | 목적 | 지우는 방법 |
|---|---|---|---|---|
| 로컬 저장소(localStorage), 이름 `beauty-feedback-v1` | 숫자 특징값(임베딩), 고친 라벨, 처음 예측한 카테고리, 모델 이름, 저장 시각, 구분용 임의 번호. **사진은 없음** | 이용자가 결과를 고칠 때만 | 이용자가 나중에 파일로 내보내 모델 개선에 쓸 수 있게 함 | 화면의 "지우기" 버튼, 또는 브라우저 설정에서 사이트 데이터 삭제 |
| 캐시 저장소(Cache Storage) | AI 모델 파일 (약 94MB\~630MB). 개인정보는 없음 | 처음 분석할 때 | 다음 방문 때 다시 내려받지 않게 함 | 브라우저 설정에서 사이트 데이터 삭제 |
| 로컬 저장소, 전문가 검수 도구(review.html)를 쓴 경우만 | 검수자가 적은 이름, 전문 분야, 사진 파일 이름, 검수 결과. **사진은 없음** | 검수자가 도구를 쓸 때 | 검수 진행 상황 보관 | 도구의 "지우기" 버튼, 또는 사이트 데이터 삭제 |
| 브라우저 일반 캐시 | 글꼴, 라이브러리, 예시 사진 파일 | 접속할 때 | 빠른 로딩 | 브라우저 설정에서 캐시 삭제 |

**거부하는 방법**

- 브라우저 설정에서 사이트 데이터 저장을 막을 수 있습니다.
  - Chrome: 설정 → 개인정보 보호 및 보안 → 서드 파티 쿠키 / 사이트 데이터
  - Safari: 설정 → 개인정보 보호 → 모든 쿠키 차단
- 저장을 막으면 피드백을 저장할 수 없고, 방문할 때마다 모델을 다시 내려받습니다. 분석 기능은 그대로 쓸 수 있습니다.

**Hugging Face 안내 페이지의 쿠키**

서비스를 huggingface.co/spaces 주소로 열면, 서비스를 감싼 Hugging Face 페이지가 Hugging Face의 정책에 따라 쿠키를 쓸 수 있습니다. 이 쿠키는 운영자가 관리하지 않습니다.

> `검토 필요` 브라우저 메뉴 이름은 버전마다 바뀝니다. 게시 직전에 다시 확인하세요.

## 제14조 (앞으로 바뀔 수 있는 부분)

다음 중 하나라도 하게 되면 이 처리방침을 먼저 고치고, 필요한 경우 이용자의 동의를 따로 받습니다.

- 피드백 파일이나 특징값을 서버로 모으는 경우
- 사진을 서버로 보내거나 저장하는 경우
- 이용 기록 분석 도구, 광고, 로그인, 결제를 붙이는 경우
- 매장이나 고객에게 학습용 사진을 받는 경우 (별도 [사진 이용 동의서](photo-consent.md) 사용)

## 변호사 검토 요청 사항 (게시 전 삭제)

1. 운영자가 개인정보를 거의 처리하지 않는 상황에서 「개인정보 보호법」상 "개인정보처리자"에 해당하는가. 해당하지 않더라도 처리방침을 게시하는 것이 권장되는가.
2. Hugging Face·jsDelivr의 접속 기록 처리를 운영자의 국외 이전·위탁으로 적어야 하는가 (제6조).
3. 개인 이메일 서비스로 문의를 받는 것을 위탁·국외 이전으로 적어야 하는가 (제5조).
4. 피드백 특징값(임베딩)이 개인정보·민감정보에 해당할 수 있는가 (제2조 제3항, 제14조).
5. 개인 운영자의 개인정보 보호책임자 표기와 연락처 표기 방법 (제12조).
6. 2026. 9. 11. 시행 개정법(법률 제21445호: 보호책임자 역할 강화, 유출 가능성 통지 등)이 이 서비스 규모에 영향을 주는가.
