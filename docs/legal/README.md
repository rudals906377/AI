### 2-5. 게시 방법 주의

- **지금 작업 중인 `tools/deploy-space.py`가 `docs/legal/*.md`를 Space에 올리도록 바뀌어 있고, 작업 중인 index.html 하단이 `docs/legal/ai-notice.md`로 연결됩니다.** 이대로 배포하면 "초안" 표시와 `검토 필요` 메모, 변호사 질문 목록이 그대로 공개됩니다.
- 변호사 검토가 끝날 때까지 이 폴더를 배포 대상에서 빼거나, 검토를 마친 뒤 공개용 문서(메모를 지운 판)를 따로 만들어 그 파일만 올리세요.
- `.md` 파일은 브라우저에서 서식 없이 보일 수 있습니다. 공개용은 HTML 페이지로 만드는 것이 읽기 좋습니다.

## 5. 변호사에게 물어볼 것 (모아 보기)

각 문서 끝에 자세한 목록이 있습니다. 가장 중요한 것만 모았습니다.

1. **주체**: 비영리 학생 프로젝트 운영자가 「개인정보 보호법」상 개인정보처리자, 인공지능기본법상 인공지능사업자, 약관법상 사업자에 해당하는가. 해당하지 않아도 문서를 게시하는 편이 나은가.
2. **국외 이전**: 운영자가 받지 않는 Hugging Face·jsDelivr 접속 기록을 운영자의 국외 이전·처리 위탁으로 적어야 하는가 (privacy.md 제6조).
3. **얼굴 관련 정보**: 기기 안에서만 쓰는 얼굴 랜드마크, 피드백 특징값(임베딩), 학습용 얼굴 사진이 민감정보(생체인식 특징정보)나 개인정보에 해당하는가.
4. **생성형 AI 범위**: 규칙으로 조립한 설명 문장이 생성형 AI 결과물인가. 서비스 이름의 "AI"로 사전 고지 예외("명백한 경우")가 되는가.
5. **약관 편입과 면책**: 회원 가입 없는 사이트에서 약관이 효력을 가지려면 무엇이 필요한가. 무료 서비스의 경과실 면책은 어디까지 가능한가.
6. **예시·학습 사진 권리**: 권리 미확인 예시 사진을 둔 채 공개해도 되는가. 매장을 통한 고객 사진 수집의 법적 구조(제3자 제공/위탁)와 작가 허락의 필요 범위.
7. **철회와 학습된 모델**: 동의 철회 후 이미 학습된 모델을 그대로 써도 되는가.
8. **미성년자와 IRB**: 만 14\~18세의 초상 이용 허락에 법정대리인 동의가 필요한가. 수업 과제의 사진 수집에 IRB 심의가 필요한가.
