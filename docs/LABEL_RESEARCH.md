# 라벨 리서치 (v2 · v3)

> **v3 (2026-10-07)**: 라벨 82개를 더해 406개가 됐다. 아래 [v3 에서 더 넣은 라벨](#v3-에서-더-넣은-라벨-2026-10-07) 참고.

한국 사용자가 실제로 검색하고 쓰는 뷰티 스타일 이름을 웹에서 찾아, 사진 한 장으로 구분할 수 있는 것만 라벨로 넣었다.
조사일은 2026년 10월 1일이고, 2024\~2026년 자료를 기준으로 했다.

## 방법

1. 카테고리마다 조사를 따로 돌렸다. 한국 패션 매거진(보그 · 엘르 · 코스모폴리탄 · 얼루어 · 마리끌레르 · 하퍼스 바자 · W · GQ 코리아), 살롱 · 네일숍 · 타투 예약 플랫폼, 뷰티 커뮤니티(언니의파우치 등), 쇼핑몰 카테고리, 스레드 · 핀터레스트 검색 결과를 봤다. 네이버 블로그는 검색 도구가 막혀 직접 인용하지 못했다.
2. 용어마다 다섯 가지를 판단했다.
   - 사진 한 장으로 보이는가
   - 어느 그룹에 들어가는가
   - 기존 라벨과 겹치는가
   - 모델에 넣을 영어 묘사
   - 실제로 쓰인다는 근거
3. 겹치는 이름은 새 라벨 대신 같은 말(`syn`)로 붙였다. 예를 들어 엘리자벳펌은 빌드펌에, 시크릿투톤은 이너컬러에, 결광은 윤광에 붙였다. 앱은 이 이름을 문장의 "\~라고도 불러요"에 쓴다.
4. 사진으로 구분할 수 없는 용어는 뺐다.
   - 시술 방식만 다른 것: 셋팅펌 · 디지털펌 · 다운펌, 뿌리 볼륨펌
   - 관리 용어: 손상모 클리닉
   - 다른 카테고리: 반영구 눈썹 · 두피 문신
5. 조사 원문의 출처는 실제로 열어 본 페이지와 검색 결과에서만 본 페이지를 나눠 적었다.

## 학습 데이터 다시 맞추기

라벨이 바뀌면 기존 정답도 바뀐다. 예를 들어 예전에 '등'으로 표시한 사진은 지금은 날개뼈일 수 있다. 그래서 학습 · 평가 사진 2,102장을 v2 라벨 목록으로 모두 다시 봤다.

- AI 에이전트 12개가 사진을 3×3 또는 2×2 묶음으로 보며 기존 라벨에서 출발해 고쳤다. 기준은 `data/LABELING_RULES.md`에 적었다.
- 사진이 아니거나 여러 장을 붙인 콜라주 63장은 뺐다. 학습용은 47장이고, 평가용 16장은 평가 세트를 유지하려고 기존 라벨을 옮겨 썼다.
- 다시 보지 않은 그룹은 기존 라벨을 새 후보 묶음으로 옮겼다. 예를 들어 등은 [등, 날개뼈, 척추, 허리·골반] 묶음이 된다.
