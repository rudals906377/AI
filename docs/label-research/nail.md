## 사진으로 구분 불가

| 용어 | 판정 | 이유 |
|---|---|---|
| 젤네일 vs 일반 매니큐어(폴리시) vs 아크릴 | 거절 | 재료 차이. 완성된 사진에서 신뢰성 있게 구분 불가 |
| 프레스온 / 네일팁 / 젤스티커(오호라 등) / 반셀프 | 거절 | 붙이는 제품과 샵 시술은 사진상 거의 같음 |
| 젤연장 vs 아크릴연장 vs 팁연장 | 길이로만 처리 | 시술 방식은 안 보임. `롱네일`로 처리 |
| 스탬핑 | 거절 (결과 패턴으로 라벨링) | 시술 기법임. 결과물은 레이스·체크·드로잉처럼 보이므로 그 라벨로 분류 |
| 젤리네일 vs 시럽네일 | 동의어 처리 | 둘 다 반투명 컬러 광택이라 사진으로 구분 불가 |
| 블러셔 네일 vs 치크 네일 vs 오라 네일 | 동의어 처리 (`치크·오라`) | 같은 시각 효과(중앙이 번지는 혈색) |
| 오로라 vs 홀로그램 vs 유니콘 파우더 | 동의어 처리 | 같은 무지개빛 반사. 제품명만 다름 |
| 크롬 vs 미러파우더 vs 메탈릭 마감 | 동의어 처리 | 같은 거울 반사 효과 |
| 진주광·미세펄 vs 글레이즈드 | 부분 중복 | 아주 얇은 펄은 글레이즈드와 거의 같음. 진하면 `글레이즈드`, 은은하면 finish `펄·쉬머` |
| 벨벳 자석 vs 벨벳 파우더(플로킹) | `벨벳`으로 통합 | 둘 다 보송하고 확산된 반짝임이라 사진에서 구분 어려움 |
| 자석 유리알 / 은하수 / 8자 / 십자 자석 패턴 | `캣아이` 동의어 | 자석 패턴 세부는 각도·조명에 따라 바뀌어서 분류 불안정 |
| 이중프렌치 / 둥근프렌치 / 헤어라인 프렌치 | 거절 또는 흡수 | 너무 세분화됨. 헤어라인은 `마이크로프렌치`, 나머지는 `프렌치` |
| 하객 네일 | `오피스·데일리`에 흡수 | 용도 이름이라 단정한 데일리 네일과 시각적으로 같음 |
| 오마카세 (원래 뜻: 네일리스트에게 맡김) | 맡김의 의미는 거절 | 비시각적 주문 방식임. "손톱마다 다른 조합"의 의미만 `오마카세` 라벨로 사용 |
| 이달의 아트 / 신상 아트 | 거절 | 샵 메뉴 이름. 디자인 정보가 없음 |
| 큐티클 케어 / 화이트태닝 / 손톱 관리 / 손톱 스킨케어 | 거절 | 관리 서비스이지 스타일이 아님 |
| 감다살 / 에겐녀 / 청량 / 몽환 / 귀염뽀짝 | 거절 | 주관적 수식어. 무드 라벨(`키치`, `청순·러블리`, `여름`)로 매핑 |
| 드뮤어 | 트렌드 키워드로 이동 | 시각적으론 미니멀+실버. 단독 라벨로는 너무 모호 |
| 슈가(설탕) 텍스처 | 보류 | 해외 기사에만 나오고 한국 근거 없음 |
