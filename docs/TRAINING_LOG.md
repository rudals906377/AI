# 반복 학습 기록 (라운드별)

스타일 사진 분석(헤어 · 네일 · 메이크업 · 타투)의 정확도 · 라벨 품질을 라운드마다 조금씩 올린다. 한 라운드는 아래 순서로 돈다.

1. **사진 보충** — Openverse · Wikimedia Commons 에서 **상업 이용 가능 · 개작 허용** 라이선스(CC0 · PDM · CC BY · CC BY-SA)만 받는다. ND · NC 는 받지 않는다. 약한 그룹을 노린 검색어를 라운드마다 바꾼다.
2. **고르기** — 아직 라벨이 없는 사진 중 지금 배포 모델이 가장 헷갈리는 사진(약한 그룹 가중) 절반 + 다양성 절반. 이미 본 사진 · 평가 세트와 거의 같은 사진(코사인 0.93 이상)은 뺀다.
3. **라벨** — 보조 AI 에이전트가 `data/LABELING_RULES.md` 기준으로 85% 이상 확신할 때만 단다. "뷰티 사진 아님"도 판별용 음성 데이터로 쓴다.
4. **라벨 재검토** — 두 모델(기본 · 정밀)의 폴드 밖 예측이 모두 지금 라벨과 다르고 같은 대안을 고른 항목, 또는 한 모델이 아주 확신한 항목을 사진을 다시 보고 판정한다 (유지 · 대안 · 직접 · 판단 불가로 삭제 · 사진 제외).
5. **재학습 · 비교** — 두 모델 헤드를 다시 학습하고, 바뀌지 않은 라벨의 폴드 밖 정확도와 평가 세트(812개 속성, 학습에 쓰지 않음)로 배포 중인 헤드와 그룹별로 비교한다. 나아진 그룹만 바꾸고, 전체가 떨어지면 배포하지 않는다.
6. **기록** — 새 라벨은 `data/rounds/rN.jsonl`, 고친 라벨은 `data/rounds/rN_fixes.jsonl` 에 남긴다 (사진 파일은 저장소에 넣지 않고 출처 · 라이선스 · 라벨만).

## 라운드 5 (2026-10-17)

- **고르기 · 라벨**: 남은 수집 사진 중 300장을 골라 라벨. 뷰티 사진으로 쓸 수 있는 것은 28장(헤어 6 · 메이크업 12 · 네일 5 · 타투 5), 뷰티 사진 아님 158장, 쓸 수 없음 113장. **기존 수집분(약 2만 장)은 사실상 다 썼다** — 남은 사진은 대부분 일반 인물 · 물건 사진이었다.
- **사진 보충**: 약한 그룹을 노린 검색어 90개로 Openverse 를 다시 훑었지만 새 사진이 검색어당 0~2장이었다 (대부분 이미 받은 사진, Wikimedia 요청 제한). 자유 라이선스 뷰티 사진은 이 두 곳에서 거의 다 모은 상태다.
- **라벨 재검토**: 학습 라벨 4,281개 사진(속성 11,405개)의 폴드 밖 예측으로 의심 항목 427개(사진 395장)를 골라 다시 봤다. 유지 293 · 대안이 맞음 40 · 직접 고침 11 · 판단 불가로 삭제 72 · 사진 제외 11. 의심 항목의 약 1/3 이 실제로 틀렸거나 판단할 수 없는 라벨이었다.
- **학습 코드 버그 2개 발견 · 수정**:
  1. 라벨을 고친 학습 목록을 만들 때, 원래 속성 라벨이 없는 사진(카테고리 판별용) 205장이 함께 빠졌다. 고친 뒤에 라벨이 다 빠진 사진만 빼도록 수정했다.
  2. 헤드 학습(`tools/train-heads.py`)의 교차 검증이 사진마다 폴드를 나눴다. 같은 작가 사진이 많아(손톱 디자인 677장 중 111장이 한 작가) 비슷한 사진이 학습 · 검증 폴드에 갈라지고, 과적합한 설정(약한 정규화)이 좋아 보였다. 그래서 사진 28장만 더해도 손톱 디자인 81 → 47%, 타투 위치 88 → 63% 처럼 평가 정확도가 무너졌다. kNN 학습(`train-knn.py`)처럼 **작가 단위**로 나누도록 고치자, 같은 목록에서 79.3% 로 안정됐다 (배포 당시 목록도 78.2 → 79.1%).

## 라운드 6 (2026-10-17)

- **사진 보충**: 약한 그룹 검색어 90개로 새 사진 727장(상업 이용 가능 677장)을 받았다.
- **고르기 · 라벨**: 352장 중 학습에 쓸 수 있는 사진 73장(헤어 18 · 메이크업 32 · 네일 4 · 타투 19), 뷰티 사진 아님 180장, 쓸 수 없음 99장.
- **재학습 · 비교**: 라운드 5 · 6 라벨과 고친 라벨로 두 모델을 다시 학습했다. 배포 헤드는 그동안 그룹마다 가장 좋은 학습 결과를 골라 합친 것이라, 새 학습 전체가 배포보다 낫지는 않았다 (기본 77.8% · 정밀 81.5%, 부위 판단 그룹 제외). **폴드 밖 정확도와 평가 세트가 모두 오르고, 부위를 잘라 판단하지 않는 그룹만** 바꿨다.

| 바꾼 그룹 | 폴드 밖 (헤드 + kNN, 앱이 쓰는 값) | 평가 세트 |
|---|---|---|
| 정밀 · 앞머리 | 81.7 → 83.2% | 74.4 → 79.5% (39개) |
| 정밀 · 메이크업 분위기 | 70.2 → 81.6% | 72.2 → 88.9% (18개) |
| 정밀 · 손톱 길이 | 85.0 → 91.2% | 57.1 → 85.7% (7개) |
| 기본 · 손톱 길이 | 77.4 → 86.3% | 57.1 → 100% (7개) |
| 기본 · 네일 분위기 | 66.8 → 76.9% | 83.3 → 100% (6개) |

(폴드 밖 수치는 라벨을 고친 뒤의 것과 고치기 전의 것을 비교하므로, 라벨 정리 효과도 섞여 있다.)

- **결과 (평가 세트 812개 속성)**: 기본 80.9 → **81.3%** (네일 84.6 → 85.8%), 정밀 83.6 → **84.4%** (헤어 83.9 → 84.9 · 네일 89.2 → 90.0 · 메이크업 72.3 → 73.5%). 쓰지 않는 kNN 사진 은행 행을 정리해 바꾼 그룹의 사진을 더하고도 헤드 파일 크기는 비슷하다 (기본 3.64 → 3.46 MB · 정밀 4.59 → 4.63 MB).
- **주의**: 평가 세트로 바꿀 그룹을 고르므로 평가 수치는 조금 낙관적이다. 표본이 작은 그룹(손톱 길이 7개 · 네일 분위기 6개)은 폴드 밖 정확도도 함께 오른 경우만 바꿨다.
- **다음 라운드**: 여러 언어(스페인어 · 프랑스어 · 이탈리아어 · 포르투갈어 · 독일어 · 일본어 · 한국어) 검색어 86개로 사진을 더 받는 중이다. 처음 11개 검색어에서 새 사진 216장 (검색어당 약 20장, 라운드 6 영어 검색어는 약 8장).

## 라운드 7 (2026-10-17)

- **사진 보충**: 영어 대신 **여러 언어**(스페인어 · 프랑스어 · 이탈리아어 · 포르투갈어 · 독일어 · 일본어 · 한국어) 검색어 86개로 새 사진 1,289장을 받았다 (상업 이용 가능 1,148장). 영어 검색어(라운드 6, 검색어당 약 8장)보다 훨씬 많이 나왔다 (검색어당 약 15장).
- **고르기 · 라벨**: 이번에 새로 받은 사진만 대상으로 347장을 골라 **학습용 224장**(헤어 33 · 메이크업 90 · 네일 29 · 타투 72), 뷰티 사진 아님 44장, 쓸 수 없음 78장. 사용 가능 비율이 라운드 5 · 6 (약 10~20%) 에서 **65%** 로 올랐다. 원본을 열어 볼 수 없던 사진 1장은 시트로만 본 것이라 학습에서 뺐다.
- **학습 최적화 문제 발견 · 수정**: 사진을 224장 더했는데 기본 모델 후보가 오히려 77.8 → 75.4% 로 떨어졌다. 한 그룹씩 λ 를 바꿔 다시 맞춰 보니 **학습 데이터 정확도 자체가** λ 에 따라 90 → 66 → 77% 처럼 들쭉날쭉했다 (λ 가 커질수록 고르게 내려가야 정상). 헤드 학습(Adam 150 스텝 · 학습률 0.03 · 온도도 함께 학습)이 수렴하지 않은 것이다. 600 스텝 · 0.005 로 바꾸자 고르게 내려가고, 라운드 6 · 7 목록에서 결과가 거의 같아졌다. 같은 목록 후보가 기본 75.4 → **79.4%**, 정밀 81.7 → **83.1%** (부위 판단 그룹 제외). `tools/train-heads.py` 기본값을 바꿨다 (학습 시간은 약 4배).
- **바꾼 그룹** (같은 목록의 이전 설정 후보보다 폴드 밖 정확도가 떨어지지 않고, 평가 세트가 오른 그룹):

|---|---|---|
| 기본 · 앞머리 | 73.5 → 84.7% | 92.3 → 97.4% (39개) |
| 기본 · 네일 배치 | 75.4 → 78.6% | 64.2 → 69.8% (53개) |
| 기본 · 타투 장르 | 70.7 → 70.5% | 80.0 → 82.5% (40개) |
| 기본 · 타투 색 | 77.7 → 80.6% | 77.1 → 79.2% (48개) |
| 기본 · 타투 위치 | 79.8 → 82.5% | 87.8 → 90.2% (41개) |
| 정밀 · 타투 주제 | 78.8 → 79.1% | 83.8 → 86.5% (37개) |

  정밀 모델의 손톱 디자인 · 타투 색 · 타투 크기는 평가 세트는 올랐지만 폴드 밖 정확도가 떨어져 바꾸지 않았다.

- **다음 라운드**: 다른 언어(네덜란드어 · 폴란드어 · 튀르키예어 · 인도네시아어 · 베트남어 · 중국어 · 러시아어)와 새 스타일 이름 92개로 사진을 받는 중. 부위를 잘라 판단하는 헤드(기본 메이크업 · 헤어, 정밀 메이크업)도 새 최적화 설정으로 다시 학습해 봤지만, 같은 교차 검증에서 대부분 조금 낮았다 (기본 메이크업: 아이섀도 60.9 → 58.5 · 아이라인 66.0 → 64.0 · 립 81.6 → 80.0%). 사진이 적은 부위 데이터에서는 짧은 학습이 과적합을 막는 역할을 한 것으로 보여, 부위 헤드는 그대로 두고 부위 학습(`train-region-heads.py`)은 앞으로도 예전 설정(`FIT_STEPS=150 FIT_LR=0.03`)으로 돌린다.
