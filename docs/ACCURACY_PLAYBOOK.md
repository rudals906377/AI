# 정확도 끌어올리기 — 사진 모으기 · 검수 · 학습 · 반영

지금 스타일 판단 정확도는 약 80%, 한국 스타일 사진에서는 76~78% 입니다. 가장 빠르게 올리는 방법은 **미용 전문가가 실제 한국 스타일 사진을 검수해 그 결과로 모델을 이어서 학습시키는 것**입니다.
원래 학습 사진(수천 장)이 없어도, 검수 결과 파일만으로 배포된 모델을 개선할 수 있게 도구를 만들어 두었습니다.

## 효과 (모의 실험, 2026-10-08)

모델이 한 번도 보지 않은 시험 사진 210장을 반으로 나눠, 105장을 "디자이너 검수 결과"처럼 넣고 나머지 105장으로 확인했습니다.

| | 이어서 학습 전 | 후 |
|---|---|---|
| 처음 보는 105장, 속성 판단 104개 | 70.2% | **75.0%** |
| 네일 디자인 (15개) | 80.0% | 86.7% |
| 아이섀도 (6개) | 66.7% | 83.3% |
| 타투 부위 (6개) | 33.3% | 83.3% |

- 검수 105장만으로 +4.8%p. 그룹마다 사진이 6~15장이라 숫자는 흔들릴 수 있습니다. 300~500장이면 훨씬 안정적입니다.
- 교차 검증에서 나아진 그룹만 바꾸므로, 피드백이 적거나 오히려 나빠지는 그룹은 그대로 둡니다 (이번에도 15개 그룹 중 3개만 바뀜).
- 측정은 헤드 + 제로샷 혼합 기준입니다 (앱의 kNN · 보정은 빼고 잼).

## 1. 사진 모으기 (300~500장 목표)

- **권리가 확인된 사진만**: 직접 시술한 손님 사진(촬영 · 활용 동의서 — `docs/legal/` 초안), 본인 · 지인 사진, 상업 이용 가능한 CC0 사진.
  예시 사진 100장 · 인스타 캡처처럼 권리가 확인되지 않은 사진은 넣지 않습니다.
- **골고루**: 커트 · 펌 · 컬러 · 앞머리가 다양하게, 카테고리(헤어 · 메이크업 · 네일 · 타투)별로 최소 50장.
- **실제 사용 사진처럼**: 휴대폰으로 찍은 정면 · 반측면, 밝은 곳 / 실내 조명 섞어서.

## 2. 검수 (`review.html`)

1. 사이트의 `review.html` 을 열고 이름 · 분야를 적습니다.
2. **폴더째 추가** 로 사진을 한 번에 올립니다 (사진은 브라우저 밖으로 나가지 않고, 특징값만 저장).
3. **AI가 헷갈린 사진부터** 가 켜진 상태로 위에서부터 검수합니다 — 같은 시간에 모델이 가장 많이 배우는 순서입니다.
4. 단축키: `1` 맞음 · `2` 틀림(정답 고르기) · `3` 판단 불가 · `Enter` 남은 항목 모두 맞음 후 다음. 익숙해지면 한 장에 10~20초.
5. **학습용 내보내기(JSONL)** 로 결과 파일을 저장합니다 (`beauty-review-날짜.jsonl`).

앱 사용자가 결과를 고친 기록(`beauty-feedback-*.jsonl`, 앱의 '피드백 내보내기')도 같은 방식으로 쓸 수 있습니다 (가중치는 검수의 1/3).

## 3. 학습 (`tools/finetune-heads.py`)

```bash
node tools/export-taxonomy.mjs > /tmp/taxonomy.json
# 먼저 바뀔 그룹과 교차 검증 결과만 확인
python3 tools/finetune-heads.py --heads heads/marqo-fashionSigLIP.json --labels embeddings/marqo-fashionSigLIP.json \
    --tax /tmp/taxonomy.json --feedback beauty-review-*.jsonl --dry-run
# 괜찮으면 실제로 저장
python3 tools/finetune-heads.py --heads heads/marqo-fashionSigLIP.json --labels embeddings/marqo-fashionSigLIP.json \
    --tax /tmp/taxonomy.json --feedback beauty-review-*.jsonl
```

- 검수 파일은 분석에 쓴 모델(기본 · 정밀)과 라벨 사전 버전이 같아야 쓰입니다. 정밀 모델도 개선하려면 `review.html` 에서 '정밀' 모델로 한 번 더 검수하거나, 같은 사진을 정밀 모델로 분석해 내보냅니다.
- 그룹마다 지금 모델에서 조금씩만 움직이고(벌점 λ 를 교차 검증으로 선택), 교차 검증에서 2%p 이상 나아진 그룹만 바꿉니다.
- 바뀐 그룹에는 `ft: { rows, lam, cv, before }` 기록이 남습니다.
- 사진 원본 · 전체 학습 데이터로 처음부터 다시 학습하는 방법(`tools/train-heads.py`)은 README 의 학습 절을 봅니다.

## 4. 반영

`heads/*.json` 이 바뀐 채로 main 에 합치면 자동 배포되고, 사용자 브라우저는 파일 해시가 바뀐 것을 보고 새 모델을 한 번 받습니다 (`assets.js`).
모델 카드(`docs/MODEL_CARD.md`)에 검수 장수 · 바뀐 그룹 · 교차 검증 결과를 적어 둡니다.

## 권장 리듬

|---|---|
