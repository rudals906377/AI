# 뷰티 사진 수집

상태: 수집 진행 중. 전체 수집 완료 또는 학습 반영 완료를 의미하지 않습니다.

- 목표: 406개 라벨과 156개 타투 세부 모티브 각각 새 사진 100장. 기존 학습 사진 수는 이 100장에 포함하지 않고 수집 순위에만 사용합니다.
- 순서: 헤어·네일·메이크업·타투를 순환하며 고르게 수집합니다. 기존 0장과 부족 표시(⚠) 라벨에 더 비중을 두되, 한 라벨 100장 완료를 기다리며 다른 분야를 미루지 않습니다.
- 분야: 헤어, 네일, 메이크업, 타투.
- 사진은 각 분야/대표라벨 폴더에 한 번만 저장합니다. 한 사진에 여러 라벨을 붙일 수 있습니다.
- 직접 수집한 사진입니다.

## 파일

- `전체_라벨_목록.md`: 사용자가 제공한 라벨 기준. 406개 라벨과 156개 모티브의 이름·기존 수량·부족 표시를 `progress.json` 562개 항목과 대조했습니다.

- `사진목록.csv`: 사진별 분야, 후보 라벨, 크기, 큰 얼굴 포함 여부, 중복 확인값.
- `manifest.json`: 같은 사진 목록의 구조화된 표현과 전체 SHA-256/bytes.
- `progress.json`: 562개 항목의 기존 수량, 부족 표시, 새 수집 목표와 누적 수량.
- `헤어/`, `네일/`, `메이크업/`, `타투/`: 실제 사진 파일.

## 검토 기준

라벨은 화면의 사진을 직접 검토한 후보입니다. 검색어만으로 정답을 확정하지 않으며 학습 담당자의 최종 라벨 검토가 필요합니다. `large_face`는 얼굴이나 부분 얼굴이 사진에서 크게 보이는지 육안으로 표시한 검토용 값이며, 신원 인식이나 정밀 면적 측정 결과가 아닙니다.

SHA-256이 같은 파일은 중복 저장하지 않습니다. 64비트 dHash 해밍 거리 5 이하의 사진은 유사 중복 후보로 표시하고, 검토 없이 원본을 삭제하지 않습니다. 해시 비교만으로 모든 유사 중복이 제거되었다고 보지 않습니다.

이 폴더는 `photo-collection` 브랜치에 보관합니다. 앱 자동 배포를 실행하는 `main`은 변경하지 않습니다.
